# TC11 - Employee attempts to access manager functions

**Category:** Access Control
**Priority:** High
**Related Use Case:** NFR 2.1
**Type:** Black-box

## Steps
1. Log in as employee
2. Observe the menu displayed

## Expected Result
Only the Employee Menu is shown (options 1-5).
No manager options are accessible.

## Actual Result
Employee account is shown only Employee Menu options and cannot access manager-only functions.
